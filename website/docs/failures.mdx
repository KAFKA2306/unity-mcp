UnityやVRChatの内部用語が分からなくても使えるように、**いま起きている症状から探せます**。エラー文がある場合は、そのまま検索欄へ貼り付けてください。技術的な名前が分からなくても、症状とエラー文だけで探せます。

各事例は、まず**見えている症状**を読み、その直下の**まず試すこと**を確認する構成です。技術的なタイトルは補助情報として小さく表示し、原因、環境、根拠は必要なときだけ詳細を開いて確認できます。

表示対象は、VRChatが対応するUnity `2022.3.22f1` が記録内で明示された2026年の事例です。解決策が確認できていないものは推測で埋めず、**調査中**として発生条件と根拠を残します。
