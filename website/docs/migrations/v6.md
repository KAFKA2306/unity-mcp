# v6への移行

v6ではMCP for Unity Editor windowがIMGUI中心の旧実装から**UI Toolkit**ベースへ再構築され、UIとbusiness logicをservice layerで分離する構成になりました。

## 主な変更

- Editor windowをUI Toolkit（UXML / USS）へ移行
- bridge / client configuration / path resolutionをserviceへ分離
- Python、`uv`、Claude CLIなどのpath overrideを明示化
- bridge healthをconnection statusと分けて表示
- 複数clientの一括設定を追加
- manual configurationをinline表示へ整理
- Asset Store向けserver download導線を追加
- `Cmd/Ctrl+Shift+M`でwindowを開ける

## 旧UIから変わった点

初回自動設定などのimplicitな処理を減らし、userが明示的にclientを選んで設定する方向へ変更されました。

依存関係確認はSetup Wizardへ寄せ、MCP window自体は接続・設定・health確認へ集中します。

## service layer

主な責務は次のように分かれます。

- `IBridgeControlService` — bridge lifecycleとhealth check
- `IClientConfigurationService` — MCP client設定
- `IPathResolverService` — server / uv / Claude CLI path解決
- `MCPServiceLocator` — service access point

この分離によりUI codeへfilesystem・process・network logicを直接埋め込まず、testしやすい構造にしています。

## 移行時に確認すること

1. packageをv6へ更新する
2. **Window → MCP for Unity**を開く
3. Setup WizardでPython / `uv`依存を確認する
4. 使用するMCP clientを明示的にConfigureする
5. path overrideを以前使っていた場合はAdvanced Settingsで再確認する
6. bridge healthとclient connectionを確認する

現在のUI・設定手順は[インストール](/getting-started/install)を正本として参照してください。
