# v10への移行 — Asset生成とTool Group

v10ではtool surfaceが拡張され、**tool groupによる可視性制御**、AI asset生成・import、package / physics / graphics / cameraなどのdomainが追加されました。

このページはv9系からv10へ移行する際の要点をまとめます。現在のtool数・group数はrelease時点から変わるため、[tool reference](/reference/tools)と現在のregistryを正本とします。

## 主な変更

- toolをgroup化し、`core`以外を必要時に有効化する構成へ変更
- `manage_tools`でsession単位にtool visibilityを管理
- 3D model / image生成、Sketchfab import、local model file importを追加
- camera / graphics / package / physics / profiling / UI / ProBuilderなどのdomainを拡張
- `unity_docs` / `unity_reflect`などUnity API調査surfaceを追加
- long-running operationをjob / pollingで扱う範囲を拡大
- provider credentialをUnity側のsecure storeへ置く
- project外へのunsafe writeやarchive traversalを拒否するimport guardを追加
- generated tool/resource referenceを整備

## Tool Group

高機能toolを常時LLMへ見せず、必要なgroupだけを有効化します。

```text
manage_tools(action="list_groups")
manage_tools(action="activate", group="vfx")
manage_tools(action="deactivate", group="vfx")
```

詳細は[ツールグループ](/guides/tool-groups)を参照してください。

## Asset generation / import

v10で追加されたasset generation系は通常のcore toolとは分けて扱います。代表的なoperation:

- 3D model生成
- image生成
- Sketchfab等からのmodel import
- Blenderなど外部DCCが出力したFBX / OBJ / glTFのlocal import

生成・downloadは時間がかかるため、開始callで`job_id`を受け取り、status actionで完了を確認するpatternを使います。

## provider key

外部providerのAPI keyはMCP promptやproject assetへ埋め込まず、Unity Editor側のsecure storageを使用します。

- macOS: Keychain
- Windows: Credential Manager
- Linux: Secret Service系

MCP clientは生成requestを出せますが、provider credential自体を受け取りません。

## local file import

local model importは外部toolからUnityへのhandoffとして扱います。

1. Blenderなどでfileを生成・exportする
2. MCP for Unityがprojectへimportする
3. 既存scene / material / prefab toolで配置・調整する

MCP for UnityがBlenderそのものを直接操作する契約ではありません。

## v9系からの確認事項

1. Unity packageをv10へ更新する
2. MCP client configを再確認する
3. `manage_tools(action="list_groups")`でvisible groupを確認する
4. 以前常時見えていたnon-core toolが必要なら該当groupを有効化する
5. asset generationを使う場合だけprovider keyをUnity側で設定する
6. package / compatibility変更を含むprojectではcompileとtestを実行する

## compatibility

Unity version差分は`MCPForUnity/Runtime/Helpers/`のcompatibility layerへ寄せます。version gateを変更した場合:

```bash
tools/check-unity-versions.sh
tools/check-unity-versions.sh --full
```

v10 release時の詳細な変更履歴はGitHub Releaseをsourceとして確認し、現在の使い方は[はじめに](/getting-started)と[リファレンス](/reference/tools)を参照してください。
