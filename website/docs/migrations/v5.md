# v5への移行

v5ではUnity packageの配置が旧`UnityMcpBridge`から`MCPForUnity`へ変更されました。旧packageを使っているprojectだけが対象です。

## 1. 旧packageを削除する

1. Unityで **Window → Package Manager** を開く
2. **Packages: In Project** を選ぶ
3. **MCP for Unity**を選択する
4. **Remove**を押す

![旧packageの削除](/img/v5_01_uninstall.png)

## 2. 新しいpathから導入する

Package Managerの **+ → Add package from git URL...** から次を追加します。

```text
https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity
```

![新しいMCPForUnity pathから導入](/img/v5_02_install.png)

## 3. MCP serverを再構築する

1. **Window → MCP for Unity → Open MCP Window** を開く
2. **Rebuild MCP Server**を実行する
3. success messageを確認する

## 確認

- Package Managerに**MCP for Unity**が表示される
- package sourceが`MCPForUnity` pathを指している
- MCP clientからscene情報など基本commandを実行できる

## 問題がある場合

- Unity Consoleのerrorを確認する
- Python / `uv` dependencyを確認する
- Unityを再起動し、package resolveをやり直す

現在の導入方法は[インストール](/getting-started/install)を参照してください。
